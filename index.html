Ajoutez un filigrane à n'importe quel document

L’ajout d’un filigrane sur vos documents est une bonne pratique mais certains organismes peuvent avoir besoin d’un document vierge (banques, services publics, etc.)

Le fichier filigrané sera au format PDF.

Vos fichiers ne quittent jamais votre appareil : tout le traitement est effectué dans votre navigateur, aucun envoi vers un serveur.

Chaque page est aplatie en image : le filigrane ne peut pas être retiré en éditant le PDF.

Sélectionner des fichiers : Formats supportés : jpg, png, heic, pdf (et autres images lisibles par votre navigateur).

    Votre document est prêt

      Vérifiez l’aperçu ci-dessous avant d’envoyer votre document. Le filigrane étant légèrement aléatoire, vous pouvez le régénérer.

      Bien rédiger son filigrane

      • Le destinataire : à qui est destiné le document (agence, propriétaire, employeur…).
      • L’objet : pour quel usage (location d’un logement, dossier de candidature…).
      • La date : pour limiter la réutilisation dans le temps.

      Exemple : « Document destiné exclusivement à l’agence X pour la location du logement au 12 rue Y — JJ/MM/AAAA ».
